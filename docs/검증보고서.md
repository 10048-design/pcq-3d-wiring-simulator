## 3. 구현 기구와 단자

31개 기구, 183개 단자 식별자를 등록했습니다. TB1~TB4(4P), MCCB(2P), SMPS, OCR, MC, 인버터, PLC, RY1~RY5(14P), RL1~2·YL1~2·GL1~2, PB1~PB7, SS1~SS3입니다. 미사용 핀도 선택 가능하므로 잘못된 단자 연결을 검사할 수 있습니다.

TB1 L1/L2/L3/N, TB2 E와 미사용 단자, TB3 E1/E2와 미사용 단자, TB4 T1/T2/T3/E의 화면 위치는 원본 4페이지를 따릅니다. 릴레이 1~14번은 6페이지 소켓 번호를 사용하며, 원본 소켓 그림을 펼쳐 핀을 직접 클릭할 수 있습니다. MC는 L1/L2/L3/T1/T2/T3/43/44/31/32/A1/A2, OCR은 L1/L2/L3/T1/T2/T3/95/96/98/A1/A2를 6페이지 예시에서 가져왔습니다.

PLC는 입력·출력 0~5와 각각의 COM, 전원 두 접속부, E, SG, 485+/485-를 구분합니다. PLC 전원은 시작 전 AC 220V / DC 24V 중 선택하고, 각 경우의 전원 NET을 적용합니다. 인버터는 도면의 전원 입출력 기능명과 CM/P3/P4/P5/S+/S-/E를 사용합니다.

**PB·SS·램프 실제 단자번호는 자료에 없습니다.** 숫자를 만들지 않고 “접점 위/아래”, “상단/하단 접속부”라는 도면 기능명을 사용했습니다. PLC·인버터 전원 표기는 실물 각인 이름으로 확정하지 않았습니다. 기구 외곽 위치는 원본 그대로이며, 미제공 물리 단자 위치는 기구 선택 후 목록 방식으로 제공합니다. 전선은 해당 기구에 대한 연결 표시이며 실제 단자까지의 시공 경로를 재현한 것은 아닙니다.

## 4. 정답 NET 구조

대표 문제 데이터에는 45개 NET이 있으며, 44개는 도면 연결 기준, 1개는 접지 지시 상충으로 보류합니다. 세부 전체 목록은 이 보고서 뒤에 자동으로 첨부합니다.

주전원: TB1 → OCR → MC → 인버터 → TB4. 기구 내부의 스위칭 접점·릴레이 코일·부하는 별도 소자로 취급하며 사용자 전선 그래프에서 서로 단락시키지 않습니다. 보조회로 L/N, OCR b접점 이후, PB6와 MC 자기유지 병렬분기, PB7과 MC 코일, MC b접점과 YL2, RY1~5와 표시등, PLC I/O, 인버터 다기능·시리얼 연결을 독립 NET으로 구성합니다.

## 5. JUMP 대체 배선

Union-Find로 같은 NET의 최종 연결 성분을 비교합니다. A-B-C와 A-C-B는 동일한 연결 성분이므로 둘 다 인정합니다. 정답의 개별 전선 목록과 일대일 비교하지 않습니다. 전기적으로 연결되어도 한 단자 3가닥이나 자재 위반은 별도 시공 오류가 됩니다. 6페이지 AC 릴레이 코일 13/14의 비극성 접속은 역할 교환을 허용합니다.

## 6. 압착단자 판정

전선 양 끝 각각에 압착 규격, 방향, 2개 체결 방식, 나선 노출, 피복 물림, 조임 상태를 저장합니다. 확정된 규격은 각 접속부에서 검사합니다. 명시되지 않은 규격은 null로 보류합니다. 1~6페이지에 Y형 단독 방향 및 두 단자 체결의 세부 방향은 명시되어 있지 않습니다. 해당 입력을 저장하지만 점검 기준을 추측하지 않습니다. 엔진에는 향후 검증된 방향 규칙을 추가할 수 있는 검사 경로가 있고 별도 시험 사례로 확인했습니다.

## 7. 절연튜브 판정

대표 문제는 p2 12항에 따라 **PLC의 모든 단자**에서 접속부별 tube 값을 검사합니다. 입출력 COM, 전원, 접지, 통신도 포함합니다. 다른 문제의 I/O 전용 규칙은 공통 규칙으로 덮어쓰지 않고 문제별 재정의로 보존했습니다. 다른 문제에는 아직 채점 엔진을 연결하지 않았습니다.

## 8. 오류 개수 계산

서로 다른 NET을 잇는 전선은 물리 전선별 1개 연결 오류로 묶습니다. 이 연결에서 파생되는 분리 오류는 해당 잘못된 전선 하나당 최대 1개만 같은 수정 항목에 흡수해, 별도의 누락까지 숨기지 않습니다. 정상 NET이 k개 연결 성분으로 분리되어 있으면 최소 k-1개의 추가 연결 작업으로 셉니다. 이것은 수정 안내용 결정적 정책이며 모든 복합 오배선의 전역 최소 수정 집합을 최적화하는 알고리즘은 아닙니다.

색상·굵기·종류·양 끝 압착·절연튜브는 서로 다른 작업 속성이므로 각각 오류가 될 수 있습니다. 동일 접속부의 나선 노출·피복 물림·나사 불량은 조임 작업 1개로 묶고, 한 단자의 3가닥 이상 체결은 단자당 1개로 묶습니다. 잘못 연결한 전선의 회로 분류가 불명확하면 자재 오류를 임의로 추가하지 않습니다.

모든 오류는 id/type/deviceIds/terminalIds/wireIds/wrong/correct를 저장합니다. 결과 항목 클릭 시 관련 기구·단자와 전선을 강조합니다. 보류 항목은 오류 개수에 합치지 않으며, 0개여도 전체 시공 적합 판정이 아니라는 문구를 표시합니다.

## 9. 확실하게 확인하지 못한 내용

- SMPS/전원 보호도체: p1 8항은 TB4, p5는 TB2 E에 SMPS 연결을 표현하여 충돌합니다. 전기적 정답 보류.
- 실제 제품 단자 위치·번호: PLC 모델 선택과 실물 확인 없이는 확정 불가. MC/OCR도 p6에 제품에 따라 다를 수 있다고 명시.
- Y형 방향과 2개 압착단자 체결 방향: 지정 6페이지 범위에 기준 없음.
